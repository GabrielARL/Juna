Red configuration search

Four measured red channels × three hydrophones at 20 dB. Confirmation only: every retained configuration ran 60 frames on seeds 6 and 7. The harness uses linear chirp synchronization. Rates are not comparable with the earlier sonique table. Orthogonal frequency-division multiplexing with forward error correction is labeled OFDM+FEC. Partial fast Fourier transform with forward error correction is labeled Partial-FFT + FEC. The remaining labels are JUNA-Lite, C,z refinement, and joint C,W,z. Packet success ratio (PSR) and bit error rate (BER) are reported for every configuration. Cyclic prefix (CP) length and low-density parity-check (LDPC) code settings describe the confirmed geometry. A cyclic redundancy check (CRC) certifies a selected refinement checkpoint.

Reading guide

Definitions, limits, and source coverage for every view.

What does BER count?

ber = bit_errors / attempted_bits over all frames, including failed frames. Neither measure implies the other.

What is effective rate divided by?

effective_rate_bps = successful_frames × payload_bits_per_frame / (frames × frame_duration). Failed-frame time remains in the denominator. It is delivered throughput, not link rate, and it is what the search maximised.

Which configurations are retained?

Only finalists rerun over 60 frames on seeds 6 and 7: four configurations per receiver for each channel and hydrophone, twice, giving 480 rows. The 20-frame screening CSVs remain in the results directory as the search record but are not loaded into this page.

How is the confirmed winner selected?

The ranking uses mean effective rate, then lower pooled bit error rate, then lower mean decode time. The C,z confirmation reran JUNA-Lite in the same package and harness; those JUNA-Lite rows supply decode time when the first two values tie. The page also reports exact mean-rate ties before the later comparisons select one confirmed winner.

Were all five receivers searched separately?

No. Partial-FFT + FEC used its own search. C,z refinement and joint C,W,z used configurations from the shared OFDM+FEC and JUNA-Lite search. This was not a separate configuration search for the two refinement receivers, so a search for those receivers could select different configurations.

What do the refinement counters count?

Was every combination tried?

No. The driver descends one dimension at a time and only finalists reached confirmation. Factor levels are therefore unbalanced, and some levels contain only one configuration.

How should the factor ranking be read?

Bar length is the number of decades between the highest and lowest positive median BER for that receiver. An open marker means at least one level reached a median of zero; zero is reported but excluded from the logarithmic span. A long bar identifies a place to inspect, not a cause.

How should the factor panels be read?

Each point is a median BER at one factor level. A hollow point on the floor is an exact zero. A factor's own hold is ignored in its panel so that factor can still vary. Medians are used because BER spans several decades and is skewed.
