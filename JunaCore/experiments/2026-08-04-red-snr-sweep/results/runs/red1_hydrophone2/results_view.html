Red replay channel: BER versus added-noise SNR

red1 hydrophone 2 only — the other eleven capture–hydrophone paths were not run, 5 receivers, 0:2:30 dB, seed 4, 60 frames per point.

Different channel-application path from the Results page. Do not plot these curves against the 20 dB confirmation numbers. Those run through the harness's own replay and Gaussian noise; these run through the uwa-channels mixing model.

Noise. The red_noise.mat model from the same Zenodo record as the captures: α = 1.7, so the noise is impulsive, not Gaussian, and correlated across the three hydrophones. Each path decodes one hydrophone, so what reaches the receiver is that hydrophone's coloured, heavy-tailed marginal; the array correlation is present in the model but is not exercised by a single-lane receiver.

SNR. Signal power over the α-stable pseudo-power 2δ², after Mahmood & Chitre, Optimal and Near-Optimal Detection in Bursty Impulsive Noise, IEEE JOE 42(3) 2017, eq. (35). A variance-based SNR is undefined here: second-order moments do not exist for α < 2.

Geometry. The panel is held at the configuration with the lowest 20 dB BER, printed above its axes.

Reading. Hollow markers are points where no bit errors were observed; they are drawn at the half-error floor 0.5/payload bits, which is a measurement limit, not a measured value.
